# Production genesis balances (1B TKS)

Generated by `bootstrap-production-genesis.sh` from `production-genesis-input.example.json`. **No funds** are sent to legacy dev accounts (`0xe04cc55e…` Alice, `0x25451a4d…` Bob).

| Bucket | TKS | Recipient |
|--------|-----|-----------|
| Team | 150,000,000 | Auto-generated `treasury-team` ECDSA (or `address` override in input JSON) |
| Bridge | 300,000,000 | `treasury-bridge` |
| Ecosystem | 150,000,000 | `treasury-ecosystem` |
| On-chain treasury | 100,000,000 | `treasury-treasury` |
| Validators pool | 50,000,000 | `treasury-validators` |
| Public sale | 150,000,000 | `treasury-public_sale` |
| Airdrop | 100,000,000 | `treasury-airdrop` |
| Validator 1 stash | 150,000 + 100,000 bond | Validator1 ECDSA stash (consensus + Cipher) |
| Validator 2 stash | 150,000 + 100,000 bond | Validator2 ECDSA stash |
| Multisig sudo account | 1,000 | Derived 2-of-3 multisig (pays dispatch deposits) |

**Sudo:** `sudo.key` is the **multisig-derived** address (`production multisig-account`), not a single hot key.

**HyperSwarm:** Validator1/2 stash accounts are pre-registered in `shardRegistry` at genesis (2 entries).
