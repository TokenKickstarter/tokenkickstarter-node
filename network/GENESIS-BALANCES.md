# Production genesis balances (1B TKS)

Generated by `bootstrap-production-genesis.sh` from `production-genesis-input.example.json`. **No funds** are sent to legacy dev accounts (`0xe04cc55e…` Alice, `0x25451a4d…` Bob).

## Address derivation (critical)

Production H160s must match **Frontier / Ethereum** mapping: Keccak-256 of the **uncompressed** secp256k1 public key (`//secretPhrase` URI), last 20 bytes — same as `fp_account::AccountId20` and `EthereumSignature` verification.

An earlier bug used the **first 20 bytes of the compressed public key** (often `0x02…` / `0x03…`). Those addresses **cannot be signed for** with the matching private key; genesis balances there are effectively locked until spec regen + redeploy.

After fixing `get_account_id_from_seed` in `node/src/chain_spec.rs`, re-run `bootstrap-production-genesis.sh` / `assemble_tks_network_spec.py` and **reset mainnet** before sale. Audit locally: `network/scripts/audit-genesis-addresses.py` (expects `pip install eth-utils coincurve`).
